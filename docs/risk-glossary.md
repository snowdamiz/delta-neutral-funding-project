# Risk glossary

| Term | Meaning |
|---|---|
| Delta | SOL-equivalent spot exposure plus signed perp base exposure |
| Basis | Executable market value minus the relevant reference value |
| JitoSOL NAV | Stake-pool lamports per one whole JitoSOL, computed from pool state |
| Funding receipt | Cash flow to the short after preserving and then normalizing venue sign |
| Source freshness | Wall-clock age plus monotonic local age and source sequence continuity |
| Unhedged duration | Monotonic time between acquiring one leg and confirming the hedge |
| Margin ratio | Venue-authoritative collateral ratio, not locally invented leverage |
| Liquidation distance | Conservative distance from authoritative liquidation threshold |
| Unknown outcome | Submitted or simulated action whose authoritative result is not known |
| Emergency flatten | Reduce-only exit workflow that prioritizes risk over expected carry |
